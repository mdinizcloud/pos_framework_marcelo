
**Justificativa:** 
Esse framework é a melhor escolha porque a atividade exige que o modelo adote uma postura técnica específica de infraestrutura (Role) para gerar uma automação precisa (Format). Isolar a Task garante que todas as regras de segurança, tratamento de erros e comandos de SO sejam seguidos, entregando um script pronto e seguro para produção.
